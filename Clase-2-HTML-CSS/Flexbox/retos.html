📦 Retos de Flexbox

Flexbox no se memoriza, se practica. Cada reto te pide reproducir un layout — sin mirar la solución.

📋 Cómo trabajar estos retos

  • Cada reto te muestra un layout objetivo en arte ASCII y un HTML base.
  • Tu trabajo: escribir el CSS necesario para que tu página se vea igual al objetivo.
  • No vale usar Grid, ni position: absolute, ni márgenes mágicos. Solo flexbox.
  • Para verificar: abre tu archivo en el navegador y compara con el dibujo.
1

El centrado perfecto (el clásico)

Fácil

Durante 20 años, "centrar verticalmente" fue el meme de CSS. Flexbox lo resuelve en 3 líneas. Tu reto: lograrlo.

📐 Layout objetivo

┌──────────────────────────────────────┐ │ │ │ │ │ [ HOLA ] │ │ │ │ │ └──────────────────────────────────────┘ ← contenedor ocupa toda la pantalla ← caja "HOLA" centrada horizontal Y verticalmente

📥 HTML base

<style>
  body { margin: 0; }
  .pantalla {
    /* TU CÓDIGO AQUÍ */
    background: #f0f0f0;
    height: 100vh;
  }
  .caja {
    background: #6c5ce7;
    color: white;
    padding: 30px 50px;
    border-radius: 8px;
  }
</style>

<div class="pantalla">
  <div class="caja">HOLA</div>
</div>

🎯 Misión

  1. Centra .caja dentro de .pantalla usando solo propiedades flex.
  2. Debe centrarse tanto horizontal como verticalmente.
  3. Bonus: hazlo en exactamente 3 líneas de CSS.
💡 Pistas
  • El padre necesita display: flex.
  • justify-content alinea en el eje principal (horizontal por defecto).
  • align-items alinea en el eje cruzado (vertical por defecto).

2

Navbar: logo a la izquierda, menú a la derecha

Fácil

📐 Layout objetivo

┌──────────────────────────────────────────────┐ │ [LOGO] Inicio Sobre Login│ └──────────────────────────────────────────────┘

📥 HTML base

<style>
  .navbar { /* TU CÓDIGO */ background:#2d3436; color:white; padding:1rem; }
  .navbar a { color: white; text-decoration: none; }
  .menu { /* TU CÓDIGO */ }
  .menu a { margin-left: 1.5rem; }
</style>

<nav class="navbar">
  <div class="logo">[LOGO]</div>
  <div class="menu">
    <a href="#">Inicio</a>
    <a href="#">Sobre</a>
    <a href="#">Login</a>
  </div>
</nav>

🎯 Misión

  1. Logo pegado a la izquierda, menú pegado a la derecha — en la misma fila.
  2. Ambos verticalmente centrados en la barra.
  3. Bonus: haz una segunda versión donde el menú quede centrado y el logo a la izquierda (sin tocar el HTML).
💡 Pistas
  • justify-content: space-between empuja el primer hijo al inicio y el último al final.
  • Para el bonus: margin-left: auto en uno de los hijos lo empuja al extremo opuesto.

3

Galería de 3 tarjetas iguales

Medio

📐 Layout objetivo

┌──────────┐ ┌──────────┐ ┌──────────┐ │ Tarjeta │ │ Tarjeta │ │ Tarjeta │ │ 1 │ │ 2 │ │ 3 │ │ [Botón] │ │ [Botón] │ │ [Botón] │ └──────────┘ └──────────┘ └──────────┘ ← las 3 con el MISMO ancho ← el botón pegado abajo en TODAS aunque el texto sea distinto

📥 HTML base

<style>
  .galeria { /* TU CÓDIGO */ padding: 1rem; }
  .tarjeta {
    /* TU CÓDIGO */
    background: white;
    border: 1px solid #ddd;
    border-radius: 8px;
    padding: 1rem;
  }
  .tarjeta button {
    /* TU CÓDIGO */
    background: #6c5ce7; color: white;
    border: none; padding: 0.5rem 1rem; border-radius: 4px;
  }
</style>

<div class="galeria">
  <div class="tarjeta">
    <h3>Tarjeta 1</h3>
    <p>Texto corto.</p>
    <button>Comprar</button>
  </div>
  <div class="tarjeta">
    <h3>Tarjeta 2</h3>
    <p>Texto más largo que la primera tarjeta y por eso ocupa más alto. Más texto, más alto.</p>
    <button>Comprar</button>
  </div>
  <div class="tarjeta">
    <h3>Tarjeta 3</h3>
    <p>Media.</p>
    <button>Comprar</button>
  </div>
</div>

🎯 Misión

  1. Las 3 tarjetas en una fila, con espacio uniforme entre ellas.
  2. Todas las tarjetas deben tener exactamente el mismo ancho y alto, aunque su contenido difiera.
  3. El botón debe quedar pegado al fondo de cada tarjeta, no flotando bajo el texto.
💡 Pistas
  • Para que todas tengan el mismo ancho: flex: 1 en cada tarjeta.
  • Para que tengan el mismo alto: el padre con display: flex ya alinea sus hijos por altura por default (align-items: stretch).
  • Para el botón pegado abajo: la tarjeta también debe ser flex column, y al botón le pones margin-top: auto.
  • Para el espacio entre tarjetas: gap: 1rem en el padre.

✅ Autocomprobación

4

Galería responsive con wrap

Medio

Toma tu solución del reto 3 (o copia el HTML). Ahora son 6 tarjetas, no 3. Debes lograr que se acomoden solas según el ancho de pantalla.

📐 Comportamiento esperado

Pantalla ancha (>900px): [1] [2] [3] [4] [5] [6] Pantalla media (~600px): [1] [2] [3] [4] [5] [6] Pantalla angosta (<400px): [1] [2] [3] [4] [5] [6]

🎯 Misión

  1. Las tarjetas deben "envolverse" a la siguiente fila cuando no quepan.
  2. Cada tarjeta debe tener un ancho mínimo de 180px.
  3. Sin media queries: usa solo propiedades de flex.
  4. El espacio entre tarjetas debe mantenerse consistente sin importar cuántas haya por fila.
💡 Pistas
  • flex-wrap: wrap en el contenedor permite saltar de línea.
  • Para que crezcan/encojan con un mínimo: flex: 1 1 180px.
  • gap funciona perfecto con flex-wrap.

5

Holy Grail Layout

Difícil

El "Holy Grail" fue el layout más buscado de la web durante años. Con flexbox se hace en pocas líneas — pero hay que saber combinarlas.

📐 Layout objetivo

┌─────────────────────────────────────────────┐ │ HEADER │ ← altura fija ├──────────┬───────────────────┬──────────────┤ │ │ │ │ │ NAV │ MAIN │ ASIDE │ ← el alto se adapta │ 200px │ crece y crece │ 200px │ │ │ │ │ ├──────────┴───────────────────┴──────────────┤ │ FOOTER │ ← altura fija └─────────────────────────────────────────────┘

📥 HTML base

<style>
  body { margin: 0; font-family: sans-serif; }
  .layout { /* TU CÓDIGO — altura mínima toda la pantalla */ }
  header, footer { /* TU CÓDIGO */ background:#2d3436; color:white; padding:1rem; }
  .body { /* TU CÓDIGO — la zona del medio */ }
  nav, aside { /* TU CÓDIGO */ background:#dfe6e9; padding:1rem; }
  main { /* TU CÓDIGO */ background:#f5f6fa; padding:1rem; }
</style>

<div class="layout">
  <header>HEADER</header>
  <div class="body">
    <nav>NAV</nav>
    <main>MAIN — esta zona crece</main>
    <aside>ASIDE</aside>
  </div>
  <footer>FOOTER</footer>
</div>

🎯 Misión

  1. Header y footer ocupan toda la ancho, con altura natural (su contenido).
  2. NAV de 200px de ancho fijo a la izquierda.
  3. ASIDE de 200px de ancho fijo a la derecha.
  4. MAIN ocupa todo el espacio restante en el centro.
  5. Si hay poco contenido, el footer debe quedar pegado al fondo de la pantalla (no flotando arriba).
  6. Solo con flexbox. Sin grid, sin position absolute.
💡 Pistas
  • Necesitas flexbox anidado: el .layout es column, el .body es row.
  • Para que ocupe toda la pantalla: min-height: 100vh.
  • Para que el medio crezca: flex: 1 en .body (dentro del layout column) y en main (dentro del body row).
  • flex-basis: 200px; flex-shrink: 0; en nav y aside los fija.

Bonus — Reproduce esta pantalla

Difícil

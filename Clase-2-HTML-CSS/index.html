Clase 2 — HTML & CSS

Estructura y estilo: los dos pilares de cualquier interfaz web.

🎯 Objetivos de la clase

  • Entender HTML como estructura y CSS como presentación, y por qué se separan.
  • Escribir HTML semántico y accesible (no solo <div>).
  • Dominar selectores, especificidad, box model y la propiedad display.
  • Resolver layouts reales con Flexbox (1D) y CSS Grid (2D).
  • Saber cuándo usar cada uno y combinarlos en proyectos reales.

🛤️ Ruta sugerida

  1. Lee la teoría de cada tema (en orden).
  2. Cuando termines un tema, ve a sus retos antes de pasar al siguiente.
  3. Al final de toda la clase, resuelve el ejercicio integrador que combina los 4 temas.

📚 Temas

1. Fundamentos de HTML

Estructura de un documento, etiquetas, atributos, DOM, semántica, formularios.

Teoría Retos

2. Fundamentos de CSS

Selectores, especificidad, box model, clases vs ids, display.

Teoría Retos

3. CSS Flexbox

Layout 1D: alinear, distribuir, envolver y centrar en una dirección.

Teoría Retos

4. CSS Grid

Layout 2D: filas, columnas, áreas y diseños complejos en pocas líneas.

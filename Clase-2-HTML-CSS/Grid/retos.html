🧮 Retos de CSS Grid

Grid resuelve en una propiedad lo que Flexbox necesita anidado. Aprende cuándo usarlo construyéndolo.

📋 Cómo trabajar estos retos

  • Cada reto te muestra un layout objetivo. Tu trabajo es escribir el CSS para reproducirlo.
  • Solo grid. Nada de flexbox, nada de floats.
  • Antes de programar: dibuja el layout en papel y enumera las filas/columnas. Te ahorrará tiempo.
  • Al terminar cada reto, intenta romperlo: cambia grid-template-columns, mueve elementos. Aprende qué pasa.
1

3 columnas iguales en una línea

Fácil

📐 Layout objetivo

┌────────┬────────┬────────┐ │ A │ B │ C │ └────────┴────────┴────────┘ ↑ las 3 con el mismo ancho ↑ 1rem de separación entre ellas

📥 HTML base

<style>
  .grid { /* TU CÓDIGO */ }
  .item {
    background: #00b894; color: white;
    padding: 2rem; text-align: center; font-weight: bold;
  }
</style>

<div class="grid">
  <div class="item">A</div>
  <div class="item">B</div>
  <div class="item">C</div>
</div>

🎯 Misión

  1. Las 3 cajas en una sola fila, con el mismo ancho.
  2. 1rem de separación entre ellas.
  3. Hazlo de DOS formas distintas: una con valores fijos (200px 200px 200px) y otra con la unidad fr.
  4. ¿Cuál de las dos sigue funcionando si redimensionas la ventana? Explícalo.
💡 Pistas
  • grid-template-columns: 1fr 1fr 1fr reparte el espacio en partes iguales.
  • repeat(3, 1fr) es lo mismo pero más limpio.
  • gap es el equivalente de gap en flex pero nació en grid.

2

Grid 2D: 3×3 con un elemento que ocupa dos celdas

Medio

📐 Layout objetivo

┌────┬────┬────┐ │ 1 │ 2 │ 3 │ ├────┼────┼────┤ │ │ 5 │ ← "4" ocupa 2 columnas │ 4 ├────┤ │ │ 6 │ ← "4" también ocupa 2 filas ├────┼────┴────┤ │ 7 │ 8 │ ← "8" ocupa 2 columnas └────┴────────┘

📥 HTML base

<style>
  .grid { /* TU CÓDIGO */ }
  .item {
    background: #55efc4; padding: 1.5rem;
    text-align: center; font-weight: bold;
  }
  .item-4 { background: #00b894; color: white; /* + spans */ }
  .item-8 { background: #00b894; color: white; /* + spans */ }
</style>

<div class="grid">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item item-4">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
  <div class="item">7</div>
  <div class="item item-8">8</div>
</div>

🎯 Misión

  1. Crea una grid de 3 columnas × 3 filas.
  2. El item "4" debe ocupar 2 columnas y 2 filas.
  3. El item "8" debe ocupar 2 columnas en la última fila.
  4. Los demás ocupan una celda cada uno (acomódalos en el orden correcto).
💡 Pistas
  • grid-column: span 2 hace que ocupe 2 columnas.
  • grid-row: span 2 hace que ocupe 2 filas.
  • Grid acomoda automáticamente los items en el orden del HTML, saltando huecos.

✅ Autocomprobación

3

Galería responsive sin media queries

Medio

Replica una galería que se adapta sola al ancho disponible, mostrando tantas columnas como quepan de un mínimo dado. Esto es el "santo grial" del responsive con CSS Grid.

📐 Comportamiento esperado

Ancho 1200px: [1] [2] [3] [4] [5] [6] Ancho 900px: [1] [2] [3] [4] [5] [6] Ancho 600px: [1] [2] [3] [4] [5] [6] Ancho 300px: [1] [2] [3] [4] [5] [6] ↑ cada celda nunca menor a 200px

📥 HTML base

<style>
  .galeria { /* TU CÓDIGO */ padding: 1rem; }
  .foto {
    background: #00b894; color: white;
    height: 150px;
    display: flex; align-items: center; justify-content: center;
    font-size: 2rem;
  }
</style>

<div class="galeria">
  <div class="foto">1</div>
  <div class="foto">2</div>
  <div class="foto">3</div>
  <div class="foto">4</div>
  <div class="foto">5</div>
  <div class="foto">6</div>
</div>

🎯 Misión

  1. Cuantas más columnas quepan, mejor — pero cada celda mínimo 200px.
  2. Cuando no quepan, deben bajar a la siguiente fila automáticamente.
  3. Cero media queries. Solo grid.
  4. Bonus: prueba auto-fit y auto-fill. Identifica la diferencia (pista: pon ventana muy ancha con pocos items).
💡 Pistas
  • La fórmula mágica: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  • auto-fit: las columnas vacías colapsan, las llenas se estiran.
  • auto-fill: deja columnas vacías, los items no se estiran de más.

4

Layout con grid-template-areas

Medio

Reproducir el "Holy Grail" otra vez — pero ahora con la sintaxis más legible que existe en CSS: grid-template-areas.

📐 Layout objetivo

┌───────────────────────────────────────┐ │ HEADER │ ├──────────┬───────────────┬────────────┤ │ NAV │ MAIN │ ASIDE │ ├──────────┴───────────────┴────────────┤ │ FOOTER │ └───────────────────────────────────────┘

📥 HTML base

<style>
  body { margin: 0; font-family: sans-serif; }
  .layout {
    /* TU CÓDIGO — define el grid y las áreas */
    min-height: 100vh;
  }
  header { /* grid-area: ?  */ background:#2d3436; color:white; padding:1rem; }
  nav    { /* grid-area: ?  */ background:#dfe6e9; padding:1rem; }
  main   { /* grid-area: ?  */ background:#f5f6fa; padding:1rem; }
  aside  { /* grid-area: ?  */ background:#dfe6e9; padding:1rem; }
  footer { /* grid-area: ?  */ background:#2d3436; color:white; padding:1rem; }
</style>

<div class="layout">
  <header>HEADER</header>
  <nav>NAV</nav>
  <main>MAIN</main>
  <aside>ASIDE</aside>
  <footer>FOOTER</footer>
</div>

🎯 Misión

  1. Define el grid con grid-template-areas describiendo el layout como un dibujo.
  2. Asigna a cada elemento su grid-area con un nombre semántico.
  3. Header y footer abarcan todo el ancho. NAV y ASIDE 200px, MAIN ocupa el resto.
  4. Bonus: agrega una @media (max-width: 700px) que reordene las áreas a una sola columna (header → nav → main → aside → footer) cambiando solo el grid-template-areas, sin tocar el HTML ni los grid-area individuales.
💡 Pistas
  • La sintaxis dibuja el layout: grid-template-areas: "header header header" "nav main aside" "footer footer footer";
  • Combínalo con grid-template-columns: 200px 1fr 200px; y grid-template-rows: auto 1fr auto;
  • Los nombres se inventan: "header", "main", "loquesea". Lo importante es la consistencia.

Reproducir un dashboard

Difícil

📐 Layout objetivo

┌──────────────────────────────────────────────┐ │ HEADER │ ├────────┬──────────────────────────────────────┤ │ │ ┌──────┐ ┌──────┐ ┌──────┐ │ │ │ │ KPI1 │ │ KPI2 │ │ KPI3 │ │ │ │ └──────┘ └──────┘ └──────┘ │ │ SIDE │ ┌─────────────────┐ ┌────────┐ │ │ BAR │ │ │ │ │ │ │ │ │ GRAFICO │ │ LISTA │ │ │ │ │ GRANDE │ │ │ │ │ │ └─────────────────┘ └────────┘ │ └────────┴──────────────────────────────────────┘

🎯 Misión

  1. Diseña el HTML desde cero (sidebar fijo a la izquierda, header arriba, área de contenido a la derecha).
  2. Dentro del área de contenido: 3 tarjetas KPI en fila + un gráfico grande + una lista lateral.
  3. Usa grid anidado: un grid para el layout principal y otro grid dentro del área de contenido.
  4. El gráfico ocupa 2/3 del ancho del área de contenido; la lista 1/3.
  5. Todo debe ser responsive: en pantallas chicas, la sidebar pasa arriba y los KPIs se apilan.
💡 Pistas
  • Empieza por dibujar el layout en papel y nombrar cada zona.
  • Layout principal: grid 2 columnas (sidebar + contenido) y 2 filas (header + body).
  • Para anidar: el contenedor de contenido también es display: grid.
  • Para los KPIs usa lo que aprendiste en el reto 3 (auto-fit, minmax).

Bonus — Grid vs Flexbox

Difícil

Toma uno de tus retos de Flexbox y reescríbelo con Grid. Luego toma uno de tus retos de Grid y reescríbelo con Flexbox. Identifica cuál fue más natural para cada caso y por qué.

Después de hacer este ejercicio, deberías poder responder con confianza: "Grid es para layouts 2D donde controlo filas Y columnas. Flexbox es para alinear cosas en una sola dimensión." Si no lo puedes explicar, repite el ejercicio con otro reto.

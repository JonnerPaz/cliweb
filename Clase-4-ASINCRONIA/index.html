Clase 4 — Asincronía

El navegador no espera por nadie. Aprende a coordinar operaciones que tardan tiempo: promesas, async/await y consumo de APIs.

🎯 Objetivos de la clase

  • Entender por qué JavaScript necesita asincronía y cómo funciona el event loop.
  • Dominar promesas: crearlas, encadenarlas y manejar errores.
  • Usar async/await para escribir código asíncrono que se lee como síncrono.
  • Combinar operaciones con Promise.all, race y allSettled.
  • Consumir APIs reales con fetch: GET, POST, manejo de errores, concurrencia.

🛤️ Ruta sugerida

  1. Empieza por Asincronía — la base conceptual (callbacks, promesas, async/await).
  2. Resuelve sus retos antes de pasar a Fetch.
  3. Continúa con Fetch API y sus retos.
  4. Cierra con el Ejercicio PokeAPI — ya tienes UI lista, solo escribes el JS.
  5. El ejercicio integrador combina todo en una mini-app real.

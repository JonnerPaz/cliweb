Clase 3 — JavaScript

El lenguaje que da vida al navegador. De variables a interfaces que reaccionan al usuario.

🎯 Objetivos de la clase

  • Dominar la sintaxis fundamental: variables (let/const), funciones, arrays y objetos.
  • Manipular el DOM: seleccionar, modificar, crear y eliminar elementos.
  • Reaccionar a la interacción del usuario con eventos (clicks, teclado, formularios).
  • Trabajar con JSON: parsear, serializar, transformar y validar datos.
  • Comprender la diferencia entre código que describe (HTML/CSS) y código que ejecuta (JS).

🛤️ Ruta sugerida

  1. Empieza por Javascript Basics — sin esto, lo demás no tiene sentido.
  2. Pasa a DOM — cómo JavaScript "ve" y modifica el HTML.
  3. Luego Events — cómo JavaScript reacciona a lo que hace el usuario.
  4. Cierra con JSON — el formato universal para enviar/recibir datos.
  5. Al final, resuelve el ejercicio integrador: una mini-app que usa los 4 temas.

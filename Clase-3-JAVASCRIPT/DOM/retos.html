🛠️ Retos de Manipulación del DOM

El DOM no se memoriza: se toca, se rompe y se reconstruye. Cada reto te entrega un punto de partida — tu trabajo es escribir el JavaScript que lo transforma.

📋 Cómo trabajar estos retos

  • Copia el código base a un archivo nuevo (ej. reto1.html) y ábrelo en el navegador.
  • Abre la consola (F12) — es tu mejor amiga para inspeccionar el DOM mientras lo modificas.
  • Lee la misión antes de escribir una sola línea. Asegúrate de entender qué pide.
  • Intenta solo primero. Las pistas están en un desplegable — úsalas solo si te atascas.
  • Marca los criterios de la autocomprobación cuando los vayas cumpliendo.
  • Bonus track: después de resolverlo, borra todo el archivo y reescríbelo desde cero sin mirar. Ahí es cuando realmente lo aprendes.
1

Selección de elementos: el zoológico de queries

Fácil

Antes de modificar el DOM hay que saber apuntarle. Tienes un HTML con elementos variados; tu trabajo es escribir las consultas correctas y entender la diferencia entre los métodos clásicos (getElementById, getElementsByClassName) y los modernos (querySelector, querySelectorAll).

📥 HTML base — cópialo tal cual

<!DOCTYPE html>
<html lang="es">
<head><meta charset="UTF-8"><title>Reto 1</title></head>
<body>
  <h1 id="titulo">Catálogo de productos</h1>
  <ul id="lista">
    <li class="producto destacado">Laptop</li>
    <li class="producto">Teclado</li>
    <li class="producto destacado">Monitor</li>
    <li class="producto">Mouse</li>
  </ul>
  <p data-tipo="aviso">Stock limitado.</p>

  <script>
    // Escribe tus consultas aquí
  </script>
</body>
</html>

🎯 Misión

  1. Obtén el <h1> usando getElementById y muéstralo en consola.
  2. Obtén el mismo <h1> usando querySelector. ¿Qué cambia?
  3. Obtén todos los productos con getElementsByClassName y recórrelos con for.
  4. Obtén los productos con querySelectorAll('.producto') y recórrelos con forEach.
  5. Obtén solo los productos destacados con un solo querySelectorAll.
  6. Obtén el párrafo de aviso usando un selector de atributo ([data-tipo="aviso"]).
💡 Pistas (úsalas solo si te atascas)
  • getElementsByClassName devuelve una HTMLCollection viva — no tiene forEach directo. Por eso muchos prefieren querySelectorAll, que devuelve una NodeList estática y sí soporta forEach.
  • Para combinar clases en CSS/queries: .producto.destacado (sin espacio = ambas clases en el mismo elemento).
  • Los atributos van entre corchetes: querySelector('[data-tipo="aviso"]').

2

textContent vs innerHTML vs innerText

Fácil/Medio

Este código casi funciona, pero mezcla las tres propiedades sin criterio y termina mostrando etiquetas HTML como texto plano o ejecutando código por error. Tu misión: identificar qué está mal y arreglarlo.

📥 Código base

<!DOCTYPE html>
<html lang="es">
<head><meta charset="UTF-8"><title>Reto 2</title></head>
<body>
  <div id="saludo"></div>
  <div id="mensaje"></div>
  <div id="comentario-usuario"></div>

  <script src="app.js"></script>
</body>
</html>
// app.js — todo lo de aquí está mal o mal usado. Arréglalo.

const saludo = document.getElementById('saludo');
saludo.innerHTML = 'Hola <strong>Mundo</strong>';
// ↑ Queremos que "Mundo" se vea en negrita. ¿Está bien usar innerHTML aquí?

const mensaje = document.getElementById('mensaje');
mensaje.textContent = '<em>Bienvenido al curso</em>';
// ↑ Queremos que la palabra esté en cursiva. ¿Por qué no funciona?

// Imagina que este texto vino de un input de usuario:
const inputUsuario = '<img src=x onerror="alert(\'hackeado\')">';
const comentario = document.getElementById('comentario-usuario');
comentario.innerHTML = inputUsuario;
// ↑ ¿Qué problema de seguridad hay aquí?

🎯 Misión

  1. Explica con tus palabras la diferencia entre textContent, innerHTML e innerText.
  2. Arregla el saludo: que "Mundo" aparezca en negrita y sea claro por qué ahí sí usas innerHTML.
  3. Arregla el mensaje: si quieres cursiva, ¿cuál es la solución sin usar innerHTML? (Pista: crea el elemento <em> y úsalo).
  4. Para el comentario del usuario: nunca uses innerHTML con datos no confiables. Cámbialo por la propiedad segura.
  5. Bonus: demuestra el ataque de XSS — ejecuta primero el código tal cual (verás el alert) y luego arréglalo.
💡 Pistas
  • textContent: escribe texto plano. Lo que pongas se ve literal, etiquetas incluidas.
  • innerHTML: interpreta HTML. Útil cuando tú controlas el contenido. Peligroso con datos del usuario.
  • innerText: parecido a textContent pero respeta el CSS (display:none, etc.) y es más lento.
  • Para crear un elemento: const em = document.createElement('em'); em.textContent = 'Bienvenido al curso'; mensaje.appendChild(em);

Construye una lista desde un array (sin innerHTML)

Medio

Tienes un array de tareas en JavaScript. Tu misión es generar una lista <ul> con un <li> por cada tarea — pero usando únicamente createElement y appendChild. Prohibido innerHTML.

📥 Código base

<!DOCTYPE html>
<html lang="es">
<head><meta charset="UTF-8"><title>Reto 3</title></head>
<body>
  <h1>Mis tareas</h1>
  <div id="contenedor"></div>

  <script src="app.js"></script>
</body>
</html>
// app.js
const tareas = [
  'Estudiar el DOM',
  'Hacer los retos',
  'Repasar selectores',
  'Dormir 8 horas'
];

const contenedor = document.getElementById('contenedor');

// TU CÓDIGO AQUÍ:
// 1. Crea un <ul>
// 2. Por cada tarea, crea un <li> con la tarea como texto
// 3. Mete cada <li> dentro del <ul>
// 4. Mete el <ul> dentro del contenedor

🎯 Misión

  1. Genera la lista usando solo createElement, textContent y appendChild.
  2. Cada <li> debe tener la clase tarea (usa classList.add).
  3. El primer <li> debe tener además la clase activa.
  4. Refactor: envuelve la lógica de crear el <li> en una función crearItem(texto) que devuelva el elemento ya armado.
💡 Pistas
  • Flujo: createElement → configurar (texto, clases) → appendChild al padre.
  • Para iterar con índice: tareas.forEach((tarea, i) => { ... }).
  • La función crearItem debe terminar con return li; — la responsabilidad de meterlo en el árbol es de quien la llame.

4

Eliminar elementos y manipular atributos

Medio

Recibes un DOM ya armado con varias tarjetas. Tu misión: eliminar las que cumplan cierta condición y modificar los atributos/clases de las que sobrevivan.

📥 Código base

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8"><title>Reto 4</title>
  <style>
    .tarjeta { padding:1rem; margin:.5rem; border:2px solid #ccc; border-radius:8px; }
    .destacada { border-color:#8e44ad; background:#faf5fc; }
    .oculta { opacity:.4; }
  </style>
</head>
<body>
  <section id="tarjetas">
    <div class="tarjeta" data-precio="100">Producto A — $100</div>
    <div class="tarjeta" data-precio="50">Producto B — $50</div>
    <div class="tarjeta" data-precio="300">Producto C — $300</div>
    <div class="tarjeta" data-precio="20">Producto D — $20</div>
    <div class="tarjeta" data-precio="450">Producto E — $450</div>
  </section>

  <script src="app.js"></script>
</body>
</html>
// app.js — TU CÓDIGO AQUÍ
// 1. Elimina todas las tarjetas con precio < 50
// 2. A las tarjetas con precio >= 300, agrégales la clase "destacada"
// 3. A la primera tarjeta agrégale el atributo title="Más popular"
// 4. Cambia la clase "oculta" de la última tarjeta usando classList.toggle
//    (ejecútalo dos veces y observa qué pasa)

🎯 Misión

  1. Elimina las tarjetas cuyo data-precio sea menor a 50 usando element.remove().
  2. A las tarjetas con precio mayor o igual a 300, agrégales la clase destacada (classList.add).
  3. A la primera tarjeta restante, agrégale el atributo title="Más popular" con setAttribute.
  4. Aplica classList.toggle('oculta') sobre la última tarjeta dos veces seguidas. Explica en consola qué pasa.
  5. Bonus: en vez de iterar dos veces el DOM, hazlo todo en un solo forEach.
💡 Pistas
  • parseInt(el.dataset.precio) o Number(el.dataset.precio) para convertir el data-attribute a número.
  • el.remove() es la forma moderna; el viejo el.parentNode.removeChild(el) todavía funciona pero es más verboso.
  • Si eliminas mientras iteras una HTMLCollection viva tendrás problemas — por eso conviene querySelectorAll (NodeList estática) o convertir a array con [...].
  • classList.toggle agrega la clase si no está, la quita si está. Ejecutarlo dos veces vuelve al estado original.

Mini-proyecto: tabla de productos editable

Difícil

Construye una tabla de productos donde cada fila tiene dos botones: eliminar (borra la fila del DOM) y destacar (le agrega/quita una clase visual). Todo se renderiza dinámicamente desde un array — no escribas el HTML de las filas a mano.

📥 Estructura inicial

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8"><title>Reto 5</title>
  <style>
    table { border-collapse: collapse; width: 100%; max-width: 600px; }
    th, td { padding: .6rem; border: 1px solid #ddd; text-align: left; }
    th { background: #8e44ad; color: white; }
    tr.destacada { background: #faf5fc; font-weight: bold; }
    button { margin: 0 .2rem; padding: .3rem .6rem; cursor: pointer; }
  </style>
</head>
<body>
  <h1>Inventario</h1>
  <table>
    <thead>
      <tr><th>Producto</th><th>Precio</th><th>Acciones</th></tr>
    </thead>
    <tbody id="cuerpo"></tbody>
  </table>

  <script src="app.js"></script>
</body>
</html>
// app.js
const productos = [
  { nombre: 'Laptop',  precio: 1200 },
  { nombre: 'Teclado', precio: 80 },
  { nombre: 'Monitor', precio: 350 },
  { nombre: 'Mouse',   precio: 25 }
];

const cuerpo = document.getElementById('cuerpo');

// TU CÓDIGO AQUÍ:
// Por cada producto, genera una <tr> con:
//   - una <td> con el nombre
//   - una <td> con el precio (formato "$1200")
//   - una <td> con dos botones: "Eliminar" y "Destacar"
// Los botones deben funcionar al click.

🎯 Misión

  1. Genera todas las filas dinámicamente desde el array productos. Nada de filas hardcodeadas en el HTML.
  2. El botón Eliminar debe borrar esa fila del DOM (no otra).
  3. El botón Destacar debe alternar la clase destacada sobre esa fila usando classList.toggle.
  4. Usa addEventListener para los clicks — nada de onclick en el HTML.
  5. Bonus: agrega un botón "Agregar producto" sobre la tabla que pida nombre y precio con prompt y añada una fila nueva (también funcional).
💡 Pistas
  • Cuando creas la fila dentro de un forEach, los botones tienen acceso a la tr por closure: btnEliminar.addEventListener('click', () => tr.remove());
  • Encapsula la creación en una función crearFila(producto) que devuelva una <tr> lista. Te servirá también para el bonus.
  • Otra forma de resolver el "qué fila me corresponde": dentro del handler usa event.target.closest('tr').
  • Para el bonus: valida que el precio sea un número antes de agregar (Number() + isNaN()).

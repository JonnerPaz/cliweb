🛠️ Retos de JSON

JSON no se aprende leyéndolo: se aprende parseándolo, rompiéndolo y reconstruyéndolo. Cada reto te entrega un punto de partida — tu trabajo es transformarlo.

📋 Cómo trabajar estos retos

  • Copia el código base a un archivo nuevo (ej. reto1.js) o pégalo en la consola del navegador.
  • Lee la misión antes de tocar nada. Asegúrate de entender qué se espera de la salida.
  • Intenta solo primero. Las pistas están en un desplegable — úsalas solo si te atascas.
  • Marca los criterios de la autocomprobación cuando los vayas cumpliendo.
  • Bonus track: después de resolver un reto, borra todo el archivo y reescríbelo desde cero sin mirar. Ahí es cuando realmente lo aprendes.

Parsear y acceder a datos anidados

Fácil

Recibes un string JSON desde un endpoint imaginario. Tu primera tarea siempre es convertirlo en un objeto JavaScript con el que puedas trabajar.

📥 Código base — cópialo tal cual

const respuesta = '{"usuario":{"nombre":"Ana","edad":28,"direccion":{"ciudad":"Madrid","cp":"28001"}},"hobbies":["lectura","viajes","música"]}';

// 1. Convertir a objeto
const datos = /* tu código aquí */;

// 2. Acceder a la ciudad
const ciudad = /* tu código aquí */;

// 3. Acceder al segundo hobby
const hobby = /* tu código aquí */;

// 4. ¿Cuántos hobbies tiene?
const totalHobbies = /* tu código aquí */;

console.log(ciudad, hobby, totalHobbies);

🎯 Misión

  1. Usa JSON.parse() para convertir respuesta en un objeto.
  2. Accede a usuario.direccion.ciudad.
  3. Accede al hobby en la posición 1 (recuerda: los arrays empiezan en 0).
  4. Obtén la cantidad de hobbies usando .length sobre el array (¡no sobre el objeto!).
  5. Experimento: cambia el string y mete una coma final ("música",]). ¿Qué error tira JSON.parse?
💡 Pistas (úsalas solo si te atascas)
  • JSON.parse(string) devuelve un objeto/array/valor JS según lo que contenga el string.
  • Para encadenar acceso seguro a propiedades anidadas, mira el optional chaining: obj?.a?.b.
  • Si tu string no es JSON válido (comillas simples, coma final, clave sin comillas), parse tira un SyntaxError.

Serializar con stringify (y sus rarezas)

Fácil/Medio

El camino inverso: convertir un objeto JS a string para enviarlo por red o guardarlo. JSON.stringify parece simple, pero tiene dos parámetros opcionales que casi nadie usa — y algunos valores que desaparecen silenciosamente.

📥 Código base

const producto = {
  id: 42,
  nombre: "Teclado mecánico",
  precio: 89.90,
  stock: 12,
  proveedorInterno: "secreto-no-exportar",
  saludar: function() { return "hola"; },
  descuento: undefined,
  tags: ["gaming", "rgb", "usb-c"]
};

// 1. JSON básico, una sola línea
const json1 = /* tu código */;

// 2. JSON indentado con 2 espacios
const json2 = /* tu código */;

// 3. JSON que solo incluya: nombre, precio, tags
const json3 = /* tu código */;

console.log(json1);
console.log(json2);
console.log(json3);

🎯 Misión

  1. Genera json1 con la sintaxis básica de JSON.stringify.
  2. Genera json2 usando el tercer parámetro para indentar con 2 espacios.
  3. Genera json3 usando el segundo parámetro: un array de claves que actúa como filtro.
  4. Observa: ¿qué pasó con saludar (función) y descuento (undefined)?
  5. Experimento: crea una referencia circular (producto.self = producto) y trata de serializar. ¿Qué error obtienes?
💡 Pistas
  • Firma completa: JSON.stringify(valor, replacer, espacios).
  • El segundo parámetro acepta null (no filtra), un array de strings (lista blanca de claves) o una función transformadora.
  • Funciones y undefined dentro de un objeto se omiten. Dentro de un array, undefined se convierte en null.
  • Referencia circular → TypeError: Converting circular structure to JSON.

Transformar: agrupar ventas por categoría

Medio

El caso clásico de la vida real: te llega un array de objetos crudos y necesitas resumirlos. Sin esto, no hay dashboards, no hay reportes, no hay decisiones.

📥 Código base

const ventas = [
  { id: 1, producto: "Teclado",  categoria: "Periféricos", monto: 89.90 },
  { id: 2, producto: "Mouse",    categoria: "Periféricos", monto: 25.50 },
  { id: 3, producto: "Monitor",  categoria: "Pantallas",   monto: 320.00 },
  { id: 4, producto: "Webcam",   categoria: "Periféricos", monto: 55.00 },
  { id: 5, producto: "Monitor",  categoria: "Pantallas",   monto: 280.00 },
  { id: 6, producto: "Auricular",categoria: "Audio",       monto: 120.00 }
];

// Producir un objeto resumen:
// {
//   "Periféricos": { totalVentas: N, montoTotal: M },
//   "Pantallas":   { totalVentas: N, montoTotal: M },
//   "Audio":       { totalVentas: N, montoTotal: M }
// }

const resumen = /* tu código aquí */;

console.log(JSON.stringify(resumen, null, 2));

🎯 Misión

  1. Recorre el array ventas y agrupa por categoria.
  2. Para cada categoría calcula: cuántas ventas hubo (totalVentas) y la suma de montos (montoTotal).
  3. Imprime el resultado con JSON.stringify(resumen, null, 2) para verlo bonito.
  4. Plus: redondea montoTotal a 2 decimales.
💡 Pistas
  • Array.prototype.reduce es el método natural para "colapsar" un array en un único objeto acumulador.
  • Alternativa más legible: un bucle for...of creando la clave si no existe (if (!acc[v.categoria]) acc[v.categoria] = { totalVentas: 0, montoTotal: 0 };).
  • Para redondear a 2 decimales: Number(x.toFixed(2)) o Math.round(x * 100) / 100.

Validar un JSON de formulario

Medio

Antes de guardar un payload en la base de datos, tienes que validar que tenga los campos correctos y con los tipos correctos. Nunca confíes en lo que llega de afuera.

📥 Código base

// Payload que "vino de un formulario" — puede tener errores a propósito
const payloadCrudo = '{"nombre":"Lucas","email":"lucas@mail","edad":"treinta","acepta":true}';

// Reglas:
// - nombre: string, mínimo 3 caracteres
// - email: string, debe contener "@" y "."
// - edad:  number, entre 16 y 99
// - acepta: boolean, debe ser true

function validarFormulario(jsonString) {
  const errores = [];
  // 1. Parsear con try/catch — si falla, retornar [{campo:"_root", error:"JSON inválido"}]
  // 2. Validar cada regla y empujar errores
  // 3. Retornar el array de errores (vacío si todo OK)
  return errores;
}

console.log(validarFormulario(payloadCrudo));

🎯 Misión

  1. Envuelve el JSON.parse en un try/catch. Si falla, retorna un error indicándolo y termina.
  2. Comprueba cada campo: existencia, tipo (typeof) y rango/formato.
  3. Cada error debe ser un objeto { campo: "...", error: "..." } — no un string suelto.
  4. Prueba con un payload válido y con tres payloads inválidos distintos (string roto, edad como texto, sin email).
💡 Pistas
  • typeof "hola" es "string"; typeof 30 es "number"; typeof true es "boolean".
  • Para validar email simple: email.includes("@") && email.includes("."). (Un regex completo de email es absurdamente largo.)
  • Cuidado: typeof null es "object". Si quieres asegurarte que algo es un objeto plano, también valida !== null.

Mini-API: parsear, filtrar, ordenar, serializar

Difícil

El flujo real de cualquier app web: la API te devuelve JSON, tú lo procesas en memoria, y devuelves otro JSON. Aquí simulamos toda la cadena sin fetch — solo strings.

📥 Código base

// "Respuesta" simulada de GET /api/users
const respuestaApi = '{"users":[' +
  '{"id":1,"nombre":"Ana","activo":true, "registro":"2024-03-15"},' +
  '{"id":2,"nombre":"Luis","activo":false,"registro":"2023-11-02"},' +
  '{"id":3,"nombre":"Sofía","activo":true, "registro":"2025-01-20"},' +
  '{"id":4,"nombre":"Diego","activo":true, "registro":"2024-08-08"},' +
  '{"id":5,"nombre":"Marta","activo":false,"registro":"2025-02-14"}' +
']}';

function procesar(jsonEntrada) {
  // 1. Parsear el JSON
  // 2. Quedarse solo con usuarios activos
  // 3. Ordenarlos por fecha de registro descendente (más recientes primero)
  // 4. Devolver un string JSON con la forma:
  //    { "total": N, "users": [...] }
}

const salida = procesar(respuestaApi);
console.log(salida);

🎯 Misión

  1. Parsea jsonEntrada dentro de un try/catch.
  2. Filtra con .filter(u => u.activo).
  3. Ordena con .sort() comparando fechas (ojo: hay que convertir el string a Date o comparar strings ISO directamente).
  4. Construye el objeto resultado y devuélvelo serializado con indentación de 2.
  5. La salida debe ser un string, no un objeto.
💡 Pistas
  • Las fechas en formato YYYY-MM-DD se pueden comparar como strings — el orden alfabético coincide con el orden cronológico.
  • Para orden descendente: (a, b) => b.registro.localeCompare(a.registro).
  • No modifiques el objeto parseado original más de lo necesario — encadena .filter().sort() y construye el resultado al final.
  • Recuerda: JSON.stringify(obj, null, 2) para que el resultado sea legible.

LocalStorage en JavaScript

Aprende a usar localStorage para almacenar datos en el navegador de manera persistente.

🌟 Métodos de localStorage

1️⃣ setItem() - Guardar datos

Guarda un valor en localStorage usando una clave.

localStorage.setItem("nombre", "Juan");

2️⃣ getItem() - Obtener datos

Recupera un valor almacenado en localStorage.

let nombre = localStorage.getItem("nombre");

3️⃣ removeItem() - Eliminar un dato

Elimina un valor específico de localStorage.

localStorage.removeItem("nombre");

4️⃣ clear() - Eliminar todos los datos

Borra todo el contenido de localStorage.

localStorage.clear();

5️⃣ JSON en localStorage

localStorage solo almacena texto, por lo que para guardar objetos se usa JSON.stringify() y JSON.parse().


// Guardar objeto
let persona = { nombre: "Ana", edad: 25 };
localStorage.setItem("persona", JSON.stringify(persona));

// Recuperar objeto
let datos = JSON.parse(localStorage.getItem("persona"));

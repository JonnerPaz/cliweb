5. Botón como Custom Element

Antes el navegador no sabía que tu Boton era un componente — era solo una clase tuya que generaba DOM. Ahora, extendiendo HTMLElement, tu botón se convierte en una etiqueta HTML real. El navegador lo reconoce, lo trata como cualquier otro elemento y lo puedes usar en el markup directamente.

📌 Qué cambia en este paso:
  • La clase extends HTMLElement en vez de ser una clase suelta.
  • customElements.define('mi-boton', MiBoton) registra la etiqueta en el navegador.
  • El componente se usa como <mi-boton texto="..."></mi-boton> directamente en el HTML.
  • connectedCallback() se ejecuta cuando el elemento entra al DOM — ideal para renderizar.

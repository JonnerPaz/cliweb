3. Botón Mejorado — separación CSS

En el paso 2 los estilos vivían dentro del JavaScript. Ahora los movemos a un archivo style.css y la clase solo le pone una clase CSS al elemento (button.classList.add("boton")).

📌 Qué mejoró: separación de responsabilidades (CSS = presentación, JS = lógica). La clase JS pasó de 30 líneas a menos de 15. Cualquier diseñador puede modificar el estilo sin tocar el código.
⚠️ Lo que sigue mal: el componente no tiene estado. No recuerda nada de un click al siguiente. Para componentes interactivos necesitamos estado interno.

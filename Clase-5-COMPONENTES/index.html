Clase 5 — Componentes

Cómo estructurar una aplicación dividiéndola en piezas reutilizables, paso a paso.

🎯 Objetivos de la clase

  • Entender por qué necesitamos componentes (qué problema resuelven).
  • Avanzar la abstracción paso a paso: del código repetido al componente nativo.
  • Usar extends HTMLElement + customElements.define para crear etiquetas HTML propias.
  • Aplicar este patrón para construir componentes reales: badges, contadores, toggles, modales, cards.

🛤️ La narrativa de la clase

Cada paso resuelve un problema concreto del anterior. Avanza en orden — saltarse un paso es perderse el porqué del siguiente.
